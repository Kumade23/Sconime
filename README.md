# Sconime

Streaming web app per anime, con pipeline **AnimeUnity → VixCloud** e player HLS premium.
Design stile **Apple**, dark/light mode, responsive e ottimizzato per **mobile** e **Fire TV Stick**.

---

## Avvio rapido

```bash
pip install -r requirements.txt
python app.py
```

Apri **http://localhost:5000**

Su Windows puoi anche fare doppio clic su **`avvia.bat`**.
